Data Analysis

This page documents my journey of learning scientific data analysis through real datasets. Instead of only following tutorials, I am using projects to learn how to clean data, choose meaningful variables, visualise distributions, recognise limitations, and draw careful conclusions from evidence.

My Projects

Each project begins with a real dataset and a question that I want to investigate. I document both the final results and the mistakes, decisions, and limitations involved in reaching them.

Transit vs Radial Velocity: What Do They Reveal About Exoplanets?

An exploratory analysis of confirmed exoplanets from the NASA Exoplanet Archive. I compared the orbital-period and reported-mass distributions of planets discovered through the Transit and Radial Velocity methods.

The project also examines duplicate records, missing measurements, unequal sample sizes, mass provenance, detection bias, and an apparent valley in the observed planet-mass distribution.

Finding a B± Mass Peak in CERN Open Data

My first attempt at analysing an LHCb ROOT file using Python. I extracted the reconstructed B± candidate mass, plotted its distribution, and fitted the visible peak with a simple Gaussian-plus -background model. The project focuses on learning ROOT file structure, histogram fitting, and the limits of interpreting unfamiliar scientific data.
